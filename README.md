# 웅천고 전·출입 판정 도우미

2026학년도 경상남도 고등학교 전·편입학 업무 시행 지침과 웅천고 규정집(2026. 7. 20.)을 근거로 전입·전출 가능 여부를 미리 점검하는 웹 도구입니다.

- 웹으로 쓰기: 이 저장소의 GitHub Pages 주소
- 파일로 쓰기: `files/` 폴더의 HTML 파일을 내려받아 더블클릭(엣지·크롬)
- 사용 설명서: `files/웅천고_전출입_판정_도우미_사용설명서.hwpx`
- 기초자료: `files/웅천고_전출입_기초자료.xlsx`

학생 정보는 저장하지 않습니다. 주소로 거리를 계산할 때만 주소 글자가 지도 서비스(Photon, OSRM)로 전송됩니다.
모집정원·현원은 고입포털·학교알리미 공개 자료를 중계 서버가 매일 모아 둔 값을 씁니다. 최종 허가는 전·편입학심의위원회 심의와 학교장 결정에 따릅니다.
